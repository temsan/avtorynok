Вход администратора

С галочкой кнопки управления появятся и прямо на сайте — на страницах объявлений. Без неё вход действует только в этой вкладке.

Первичная настройка: вход по токену GitHub

Объявления хранятся в репозитории GitHub . Владелец один раз входит по токену и в «Настройках» создаёт учётные записи с логином и паролем.

  1. Откройте создание токена GitHub (Fine-grained).
  2. Repository access → Only select repositories → выберите репозиторий площадки.
  3. Permissions → Repository: Contents — Read and write, Issues — Read and write. Для добавления админов — ещё Administration — Read and write.
  4. Нажмите Generate token и вставьте токен ниже.

Заявки, которые посетители отправили через форму «Продать авто». Откройте заявку в редакторе, проверьте и опубликуйте — или отклоните.

Обсуждения

Главный выключатель. Если он выключен, обсуждения скрыты у всех объявлений. Если включён — обсуждение показывается у тех объявлений, где оно включено отдельно (переключатель в списке объявлений).

Вход по логину и паролю

Пароль зашифровывает ключ доступа к GitHub (AES-256, PBKDF2 600 000 итераций). Сам пароль нигде не хранится — восстановить его нельзя, только задать новый. Используйте длинный пароль: зашифрованный ключ лежит в открытом репозитории.

Администраторы GitHub

Администратор — пользователь GitHub с правом записи в репозиторий. Он может размещать, редактировать и удалять объявления и управлять обсуждениями.

Приглашённый получит письмо от GitHub и должен принять приглашение, после чего сможет войти в админку со своим токеном.

Как снять обзор

Видео: держите телефон горизонтально на уровне фар и медленно обойдите машину ровно один круг, держа её в центре кадра. Начните и закончите в одной точке — из видео возьмутся кадры через равные промежутки.
Фото: снимите 24–72 кадра по кругу с одинаковым шагом. Порядок — по имени файла.
