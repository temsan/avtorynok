# Авторынок

Площадка объявлений о продаже автомобилей на GitHub Pages — без сервера и базы данных.

- **Сайт:** каталог с фильтрами, карточка с галереей фото, характеристиками и обзором 360°, избранное, сравнение, кредитный калькулятор, обсуждения. Устанавливается на телефон как приложение (PWA).
- **Админка:** `admin.html` — размещение, редактирование, удаление объявлений, загрузка фото и обзора 360°, модерация заявок, включение обсуждений на всём сайте и у отдельных объявлений, приглашение администраторов.
- **Управление прямо на сайте:** если админ вошёл с галочкой «Запомнить на этом устройстве», на страницах объявлений появляется панель (редактировать, статус, обсуждение, удалить), на карточках — карандаш, в шапке — «+ Объявление». Скрытые объявления админ тоже видит.
- **Автообновление:** открытые страницы раз в минуту, при возврате на вкладку и при появлении сети сами перечитывают `data/db.json` — новые объявления, фото, цены, марки в фильтрах появляются без перезагрузки.

## Как это устроено

| Что | Где хранится |
|---|---|
| Объявления и настройки | `data/db.json` |
| Фотографии | `photos/<id>/…jpg` (сжимаются в браузере до 1600 px) |
| Заявки от посетителей | GitHub Issues с заголовком `[Объявление] …` |
| Обсуждения | GitHub Issue на каждое объявление; комментарии показываются на сайте |
| Обзор 360° | `photos/<id>/360-*/<ряд>-<кадр>.jpg`; в редакторе — «Из видео» (облёт машины, MP4) или «Из серии фото» |

Админка коммитит изменения через GitHub API токеном администратора. После сохранения сайт обновляется за 1–2 минуты (сборка Pages).

## Вход администратора

Обычный вход — **логин и пароль** (например, `misha`). Пароль в браузере расшифровывает ключ доступа к GitHub, который хранится в `data/admins.json` в зашифрованном виде (AES-256-GCM, PBKDF2-SHA256, 600 000 итераций). Сам пароль нигде не сохраняется.

Первичная настройка (один раз, делает владелец репозитория):

1. Создать [fine-grained токен](https://github.com/settings/personal-access-tokens/new): Repository access → только этот репозиторий; Permissions → `Contents: Read and write`, `Issues: Read and write`.
2. Открыть `admin.html` → «Первичная настройка: вход по токену GitHub» → вставить токен.
3. Настройки → «Вход по логину и паролю» → логин `misha`, пароль (от 10 символов) → «Сохранить».

После этого misha входит только по логину и паролю. Чтобы отозвать доступ — удалить учётную запись в админке и отозвать токен на GitHub.

## Разработка

Сборки нет: `python -m http.server 8765` в корне → http://localhost:8765.

При изменении `style.css`, `common.js`, `app.js` или `admin.js` обязательно поднимите версию, иначе браузеры и установленное приложение покажут старое:
- `?v=N` у файла в `index.html` и `admin.html`;
- то же имя в списке `CORE` в `sw.js`;
- `VERSION = 'ar-vN'` в `sw.js`.
