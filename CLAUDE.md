# Авторынок — контекст проекта

Сайт объявлений о продаже авто. Статика на GitHub Pages, без сборки и зависимостей.
- Репозиторий: https://github.com/temsan/avtorynok (ветка `main`, Pages собирается из корня, есть `.nojekyll`)
- Сайт: https://temsan.github.io/avtorynok/
- Общение с пользователем — по-русски. Администратор сайта — **misha** (входит по логину и паролю).

## Файлы
| Файл | Что внутри |
|---|---|
| `index.html` + `app.js` | Публичный сайт (SPA, hash-роутинг): `#/` каталог, `#/car/<id>`, `#/favs`, `#/compare`, `#/sell` (форма заявки → GitHub Issue) |
| `common.js` | `window.AR`: REPO (по `*.github.io`, иначе `temsan/avtorynok`), ENUMS/BRANDS/CITIES/SPECS, форматтеры, `store` (localStorage), `commentsOn`, `loadPublicDb`, **обзор 360°** (`spinFrames`, `hasSpin`, `mountSpin`) |
| `admin.html` + `admin.js` | Админка: вход, список, редактор, заявки, настройки. Пишет в репозиторий через GitHub API |
| `style.css` | Вся дизайн-система (токены в `:root`, тёмная тема через `prefers-color-scheme`) |
| `data/db.json` | `{settings:{comments, defaultComments}, listings:[…]}` — вся база |
| `data/admins.json` | Учётки входа по паролю (зашифрованный токен GitHub) |
| `photos/<id>/…jpg` | Фото; `photos/<id>/360-*/<ряд>-<кадр:02>.jpg` — кадры обзора 360° |
| `sw.js`, `manifest.webmanifest`, `icons/*-g.png` | PWA: установка на главный экран |
| `photos/CREDITS.md` | Лицензии демо-фото (Wikimedia) и демо-модели 360° |

## Как устроено
- **Запись данных** — только из браузера через GitHub API (Git Data API: blobs → tree → commit → PATCH ref, повтор при 422) в `admin.js: mutate()`. Сервера нет.
- **Вход misha**: токен GitHub зашифрован AES-256-GCM ключом из пароля (PBKDF2-SHA256, 600k итераций) и лежит в `data/admins.json`. Сам пароль нигде не хранится. Токен после входа — в `sessionStorage`/`localStorage` под `ar:token`, имя — `ar:as`.
- **Обсуждения** = GitHub Issues, одно на объявление (`l.issue`). Выключение обсуждения блокирует (lock) issue. Глобально — `settings.comments`, у объявления — `l.comments`.
- **Заявки посетителей**: форма открывает new-issue с заголовком `[Объявление] …` и ```json в теле; вкладка «Заявки» в админке их разбирает.
- **Админ прямо на сайте**: если на устройстве есть `ar:token`, `app.js` грузит `admin.html?embed=1` в невидимый iframe (`.adm-frame`). Общение через `postMessage` с полем `ar:1`, сайт → админке: `edit/new/status/comments/delete`; админка → сайту: `ready/noauth/opened/closed/updated/deleted/error`. Отсюда панель `.admbar` на странице объявления, карандаш на карточках и «+ Объявление» в шапке. Админ видит и скрытые (`status: hidden`).
- **Автообновление**: сайт раз в минуту, при возврате на вкладку и при `online` перечитывает `data/db.json?t=…` (`cache: no-store`) и перерисовывает текущий экран через `apply()`. Правки админа применяются сразу и хранятся в `ADM.local`, чтобы не откатиться до публикации на Pages. Свежие фото админу показываются с `raw.githubusercontent.com`.
- **Обзор 360°**: `l.spin = {dir, cols, rows=1, row=0, note?, credit?}` или `{frames:[[url…]]}`. Мышь/палец вращают по кругу, вертикальное движение меняет ряд (высоту камеры), есть инерция, автооборот и полный экран. В редакторе: «Из видео» (кадры берутся из файла через `<video>` + canvas) или «Из серии фото» (по имени файла). У Solaris 2016 — демо из 3D-модели Car Concept (Khronos, CC BY 4.0), помечено как демо.
- **PWA**: `sw.js` — страницы, `db.json` и manifest берутся сначала из сети, статика и фото — из кеша с обновлением в фоне; админ-файлы мимо SW. При новой версии SW открытая страница сама перезагружается, если человек ничем не занят.

## Правила при правках
- **Сброс кеша**: при изменении `style.css` / `common.js` / `app.js` / `admin.js` поднимай `?v=N` в `index.html`, `admin.html` **и** в `CORE` внутри `sw.js`, а также `VERSION = 'ar-vN'` в `sw.js`. Иначе браузеры и установленное приложение покажут старое.
- Перед коммитом — `git pull --rebase`: misha постоянно сохраняет из админки, и на сервере появляются его коммиты («Изменено: …», «Статус: …»).
- Новые иконки — под новыми именами файлов, иначе Android не обновит иконку установленного приложения.
- Проверяй мобильную ширину (375 и 430 px): после увеличения шрифтов шапка впритык — надпись «Авторынок» скрывается ≤460px, в режиме админа ≤560px.
- `[hidden]` перекрыт `display:none !important` — можно смело прятать атрибутом.
- Внутри открытого `<dialog>` админки индикатор `#busy` и `#toast` переносятся в сам диалог (иначе их не видно).
- Коммиты — с подписью `Co-Authored-By`, по-русски.

## Локальный запуск и проверка
- Сервер: `python -m http.server 8765` в корне проекта → http://localhost:8765 (конфиг превью — `.claude/launch.json`).
- Настоящий токен misha никогда не вводить. Для проверки админки временно подключали заглушку GitHub API (`mock-gh.js` перед `admin.js` в `admin.html`, `sessionStorage['ar:token']='mock-test'`) — после проверки удалить и не коммитить.
- `node --check app.js admin.js common.js` — быстрая проверка синтаксиса.

## Дизайн
Шрифт Onest, базовый размер 18px (`html { font-size: 112.5% }`). Основной цвет — **зелёный** `#12a150` (hover `#0d8a43`), тёмный фон `#0e0e10`. Карточка поиска на главной всегда светлая (`.finder { color-scheme: light }`).
